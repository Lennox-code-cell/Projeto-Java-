# Mapa do projeto Biblioteca

Este arquivo é um índice de navegação do repositório. Para instruções de instalação, configuração e execução, consulte o [README.md](README.md) em português ou o [README.en.md](README.en.md) em inglês.

## Arquivos da raiz

- `pom.xml`: configuração Maven, Java 25, dependências e plugins.
- `README.md`: apresentação e instruções em português.
- `README.en.md`: apresentação e instruções em inglês.
- `.gitignore`: exclusões de arquivos locais e artefatos gerados.
- `run.bat`: execução da aplicação no Windows via Maven.
- `build.cmd`: compilação e empacotamento no Windows via Maven.

## Código-fonte

Local: `src/main/java/br/com/biblioteca/`

- `Main.java`: ponto de entrada da aplicação.
- `connection/`: conexão JDBC e configuração do banco.
- `controller/`: validação e coordenação das operações.
- `dao/`: consultas e persistência JDBC.
- `model/`: entidades e objetos do domínio.
- `util/`: validações e utilitários.
- `view/`: telas e componentes Swing.
- `TesteConexao.java`: utilitário de diagnóstico de conexão.

## Testes

Local: `src/test/java/br/com/biblioteca/`

Os testes automatizados cobrem validações e regras selecionadas dos controllers. Consulte os arquivos de teste para conhecer a cobertura efetiva.

## Banco de dados

- `sql/biblioteca.sql`: criação inicial do schema e das tabelas.
- `sql/migration_001_indexes.sql`: migração opcional de índice para consultas por data.

**Importante:** o script `sql/biblioteca.sql` cria a estrutura, mas não contém comandos `INSERT`. Os dados de demonstração precisam ser preparados separadamente. Não confunda dados existentes em uma instalação local com dados versionados neste repositório.

## Documentação adicional
